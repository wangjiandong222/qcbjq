# 运行手册

## 推荐启动方式

当前版本推荐使用“后端 8000 + 前端 5173”的本地启动方式。需要打开两个终端。

## 启动后端

```bash
cd /Users/wang/Desktop/青创北京
bash scripts/start_backend.sh
```

启动后端会自动完成：

- 创建或复用 Python 虚拟环境。
- 安装后端依赖。
- 初始化 SQLite 数据库。
- 创建默认角色、演示账号和线索标注规则。
- 启动 FastAPI 服务。

后端地址：

```text
http://127.0.0.1:8000
```

后端健康检查：

```text
http://127.0.0.1:8000/api/health
```

接口文档：

```text
http://127.0.0.1:8000/docs
```

## 启动前端

另开一个终端执行：

```bash
cd /Users/wang/Desktop/青创北京
bash scripts/start_frontend.sh
```

前端地址：

```text
http://127.0.0.1:5173
```

如果下面地址也能返回健康检查 JSON，说明前端代理到后端正常：

```text
http://127.0.0.1:5173/api/health
```

## 初始化后端

```bash
cd /Users/wang/Desktop/青创北京
bash scripts/init_backend.sh
```

通常首次启动后端时已经会自动初始化数据库。只有需要手动重建虚拟环境、安装依赖或补齐默认账号规则时，才需要单独运行初始化脚本。

## 关于 `start_web.sh`

仓库中保留了 `scripts/start_web.sh`，它会构建前端并启动后端服务。但当前后端没有挂载 `frontend/dist` 静态页面，因此完整页面访问仍建议使用：

```text
http://127.0.0.1:5173
```

如后续需要单链接内网部署，可再增加静态文件挂载、Nginx 或 Caddy 反向代理。

## 关闭系统

在启动后端和前端的两个终端中分别按：

```text
Ctrl + C
```

## 手动导入和筛查

登录后默认进入“数据导入”板块，点击“上传 Excel”，选择：

```text
本地 Excel 文件
```

上传新文件不会替换旧批次。上传完成后仅完成工单入库；Excel 不需要提供“成案领域”列，缺少标准列会自动留空，多出的列会作为额外字段保存，也支持旧版 WPS/Excel 二进制文件。需要生成分类和屡诉未决事件时，在“数据导入”板块勾选一个或多个批次，点击“运行智能筛查”；系统会根据问题分类、标签、标题、主要内容、办理结果、回复内容、主办单位、企业名称、点位和额外列等字段，结合线索标注推断公益成案领域、弱势群体、行政违法分类。未命中规则的数据进入“未知领域”或“其他”，可在详情下方人工改选并确认。

“公益成案领域”“弱势群体”“行政违法”页面均支持按分类查看数据、点击单条查看完整原始内容、选择导出、导出当前分类和去除已导出筛选。导出后对应工单会被全局标记为已导出。

“工单库”支持先选择检索字段，例如标题、主要内容、问题分类、工单编号等，再选择关键词检索或语义检索。关键词检索用于精确包含匹配；语义检索用于查找表述相近的内容，并按相似度排序。拖欠工资类数据可勾选后导出，导出文件第二列为“核心内容提炼”。

“线索标注”板块支持按业务板块新增、编辑、删除和启停。标注名称不可重复，关键词可使用中文逗号或英文逗号分隔；标注调整后需重新运行筛查，新的判断才会写回待确认分类结果。系统已删除独立导出中心，导出入口位于各业务页面右上角。
