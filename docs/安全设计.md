# 安全设计

本 MVP 默认面向政法机关内网或专有环境部署，安全策略遵循“最小权限、原始数据受控、操作留痕、外部模型可控”。

## 权限

- `admin`：系统管理、导入、筛查、复核、导出、审计。
- `prosecutor`：查看工单、筛查、复核、导出。
- `reviewer`：查看工单、复核标注。
- `viewer`：只读查看结果。

## 原始数据

- 当前版本按业务要求保留用户上传的原始数据，列表、详情、导出和模型增强均不做脱敏。
- 导出接口应纳入审批流程；MVP 中记录导出审计日志，并对已导出工单写入全局标记。
- 如后续启用外部模型，应优先使用私有化或专有云部署，并明确数据出域审批。

## 审计

系统记录以下行为：

- 登录成功和失败。
- 文件导入。
- 工单详情查看。
- 智能筛查运行。
- 线索复核。
- 大模型配置变更。
- 台账导出。

## 大模型接口

默认不启用外部模型。生产环境如需启用，应优先选择私有化或专有云部署，并明确数据出域审批、日志留存和模型供应商责任边界。
